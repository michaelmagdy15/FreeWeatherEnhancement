## MODERATE GAPS — Still Open

### 1. TAF Not Wired Into Engine or UI (verified in code, 2026-08-18)
Honest status: TafFetcher + TafDecoder exist and decode correctly, but:
- WeatherEngine instantiates a TafDecoder (dead field, WeatherEngine.cs:61) — it never calls TafFetcher.FetchTafByPositionAsync()
- WeatherState has no TafData property
- MainViewModel/MainWindow has no TAF panel

Forecast data (wind trends, BECMG/TEMPO groups, flight category) is fetched by no one. This is the last piece of forecast awareness and it's cheap.

Fix: add `TafData? CurrentTaf` to WeatherState, call TafFetcher in WeatherEngine.UpdateWeatherAsync(), add TAF panel to MainWindow.
Effort: ~20 min

### 2. REST API
Local REST API so EFBs, SimBrief, and community tools can query SkyWeave's live state without SimConnect. The extensibility moat from PLAN.md — neutralizes ASFS's paid public API.

Effort: ~2-3 days (new SkyWeave.Api project, 3-4 minimal endpoints)

### 3. Radar Overlay in UI
RadarFetcher fetches RainViewer precipitation, but the data is only used to nudge precipitation rate. No visual radar mosaic in the dashboard yet.

Effort: ~1 day (Avalonia Canvas/Image overlay with tiles)

### 4. VATSIM / IVAO Detection
Detect if the user is flying on VATSIM/IVAO and optionally defer to their weather injection to avoid conflicts.

Effort: ~1 day (process detection, event, UI indicator)

### 5. Plugin Architecture
IWeatherDataSource interface + discovery so the community can add data sources. Design-heavy — deferred to v0.5 until the REST API proves the extension surface.

Effort: ~1-2 wks (design-heavy)

### 6. SimConnect Traffic Feed for Real Wake Encounters
WakeTurbulenceEngine currently works from a traffic model; feeding it live AI/multiplayer traffic via SimConnect makes wake encounters real — you feel the heavy that landed ahead of you.

Effort: ~1-2 wks

### 7. ERA5 Historical Mode
Open-Meteo historical API exposes ERA5 — the ASFS Advanced Historical / StrataWx Historical killer feature, free.

Effort: ~3-4 days (replay mode + UI scrubber)

### 8. SimBrief Integration
Fetch flight-plan routes to pre-brief hazards along the route.

Effort: ~1-2 days
